## 7. Confirmed Product Decisions

- The MVP targets Pakistan first.
- International expansion is a future goal.
- The first version should be built with free or near-zero-cost tools.
- The first release should prioritize essential marketplace functionality.
- Students and parents can submit tutoring requests.
- Tutors can submit applications.
- Tutor profiles must be reviewed before publication.
- Private applications and student requests must not be exposed publicly.
- Login, payments, booking, messaging, and a custom admin dashboard are future features unless the project scope is explicitly updated.

Do not change these decisions without recording the reason and confirming any significant scope change with the project owner.
